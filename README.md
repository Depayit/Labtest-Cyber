# 💳 Carding Infrastructure Lab

## 🏅 เหรียญ 2 ด้าน: Cybercrime
### 🚀 บทนำ: จุดเริ่มต้นของการเดินทาง
**แรงบันดาลใจ ประสบการณ์การเรียนรู้ด้าน Cybersecurity และ Cybercrime**

การเรียนรู้นี้รวบรวมประสบการณ์ความรู้และบทเรียนที่ได้รับตลอดการเดินทางในโลกของ Cybersecurity และ Cybercrime จนเชียวชาญ โลกไซเบอร์เป็นโลกที่ซับซ้อนมีหลายมิติ และมีหลายฝั่งที่เชื่อมโยงกันเหมือนเหรียญสองด้านที่แยกไม่ออก ฝั่งหนึ่งคือผู้ป้องกัน อีกฝั่งคือผู้โจมตี ทั้งสองฝั่งต่างเรียนรู้จากกันและกัน

การเดินทางของผมเริ่มต้น จากการที่ผมได้รู้จักกับรุ่นพี่คนหนึ่งเป็นแฮกเกอร์มือโปรจบจาก Stanford University เขาอยู่ยุคเดียวกับ Mark Facebook และเป็นอาจารย์ของผม ผมได้เห็นวิธีการหาเงินจาก Dark-Net เพียงไม่กี่คลิ้กบน Browser 5-6 ชั่วโมงหลังจากนั้นก็มีของมาส่งที่มีมูลค่าสูง (เมื่อ 5-6 ปี ที่แล้ว) และหลังจากนั้นผมก็โดนความโลภครอบงำและหลงไหล ช่องทางสื่อสารตอนนี้ใช้ Telegram เป็นหลักมันคือ Social Community Version TOR ชัดๆถ้าสภาพจิตใจและไม่พร้อมสูญเสียเพื่อแรกบางอย่าง เนะนำอย่าคิดที่จะเข้ามาในวงการนี้มันเสียเวลา 

เข้าเรื่องต่อผมอยากเข้าใจว่าระบบดิจิทัลทางการเงินที่เราใช้ทุกวันนั้นทำงานอย่างไรมีช่องโหว่อะไรบ้างและคนที่มีความรู้สามารถทำอะไรได้บ้างกับระบบเหล่านี้ สิ่งสำคัญที่เป็นแรงพลักดันก็คือผลสำเร็จที่ผมได้ศึกษาหาความรู้ที่ไม่มีการสอน บทเรียนนอกตำรางคุณจะต้องเสียเงินจำนวนไปเรื่อยๆ  ใช่ครับสิ่งเดียวที่จะหาความรู้พวกนี้ได้คือการลองผิดลองถูกและตั้งใจอดทนพยายามอย่างหนักตลอดหลายปีมานี้กว่าจะสามารถทำผลงานชิ้นแรกในฝั่งผิดกฏหมายได้นั้นหมดเงินเสียเวลาไปหลายปีเพื่อที่อยากจะเอาชนะระบบ AI และท้าทายความสามารถตัวเองพร้อมอยากรู้ไปตามๆกันผลสำเร็จก็คือเงิน และจนวันนึงผมอยากนำเสนอสิ่งเหล่านี้ให้ทุกคนทราบว่าในโลกนี้มันมีอะไรที่เราไม่คาดคิดเยอะเยะและอุตสาหกรรมนี้มีเรื่องการเมืองและภาครัฐเกี่ยวข้อง พวกเขาไม่ได้ปราบปรามเหมือนเมื่อก่อน พวกเขาแค่ค้นพบวิธีที่จะอยู่ร่วมกันและหาประโยชน์จากสิ่งนี้ ผมต้องการเข้าใจทั้งสองด้านทั้งฝั่งที่ถูกกฎหมายและฝั่งที่อยู่ในเงามืด เพราะการเข้าใจอาชญากรรมไซเบอร์คือการเข้าใจว่าต้องป้องกันอย่างไรการเข้าใจตลาดมืดคือการรู้ว่าภัยคุกคามมาจากไหน โลกนี้มันโหดร้ายและผลประโยชน์คือ อันดับ 1 

> ผมมีพื้นฐานด้านเทคโนโลยีและความเข้าใจเบื้องต้นเกียวกับระบบคอมพิวเตอร์พื้นฐาน การใช้งาน Operating Systems และโปรแกรมทั่วไปความเข้าใจพื้นฐานว่าข้อมูลเดินทางอย่างไรความสนใจในเทคโนโลยีการติดตามข่าวสารด้าน Tech และ Security ความอยากรู้อยากเห็นความสงสัยว่าสิ่งต่างๆทำงานอย่างไรแต่สิ่งที่สำคัญที่สุดคือทัศนคติในการเรียนรู้ผมเชื่อว่าการเข้าใจทั้งสองด้านของเหรียญจะทำให้เห็นภาพรวมได้ชัดเจนขึ้น

## 🌐 โครงสร้างของโลกไซเบอร์
ก่อนที่จะเจาะลึกในแต่ละระดับ ผมอยากให้เข้าใจโครงสร้างใหญ่ของโลกไซเบอร์ก่อน เพื่อที่จะได้เห็นภาพรวมว่าเรากำลังจะเดินทางไปที่ไหน **Cyber Ecosystem แบ่งออกเป็น 5 ภาคส่วนหลัก** ที่เชื่อมโยงและส่งผลกระทบซึ่งกันและกัน

* Defense Contractors
* Cyber Warfare Units

* มหาวิทยาลัยและ Security Labs
* Security Researchers และ Exploit Developers

* FinTech และ Payment Processors
* Cryptocurrency Exchanges
* E-commerce Platforms

> **ข้อสังเกต:** โลกไซเบอร์เป็นเหมือน ระบบนิเวศที่เชื่อมโยงกัน ผู้โจมตีและผู้ป้องกันต่างเรียนรู้จากกันและกัน พัฒนาไปพร้อมกัน สิ่งที่เกิดขึ้นในฝั่งหนึ่งจะส่งผลกระทบไปยังอีกฝั่งทันที

## 🎯 เป้าหมายของการเรียนรู้นี้
บทความนี้จะพาคุณเดินทางรู้จักกับ **อุตสาหกรรมบริการทางการเงิน (Financial Services)** ความรู้และการวิเคราะห์ทั้งหมด พื้นฐานเครื่องมือที่ใช้ฝั่งที่ผิดกฏหมายนั้นคิดยังไง มีการวิเคราะห์และกระบวนการทำงานยังไง ใช้เป็นแนวทางในการตั้งรับของฝั่งที่ถูกกฏหมาย

> **⚠️ คำเตือนสำคัญ:** ความรู้ที่แบ่งปันนี้มีวัตถุประสงค์เพื่อการศึกษาและการป้องกัน ไม่ใช่เพื่อการทำผิดกฎหมาย การใช้ความรู้เหล่านี้ในทางที่ผิดอาจส่งผลร้ายแรงต่อตัวคุณเองและผู้อื่น ผมขอไม่มีส่วนรับผิดชอบใดๆทั้งสิ้น

## 💳 การเริ่มต้น
ผมจะมาพูดถึงสิ่งที่ผมถนัดมากที่สุด สาบานให้ตายเลยว่าผมเขียนโค้ดไม่เก่ง หลายๆ คนอาจจะเริ่มจากการ basic hacking หรือ เคยอ่านในหนังสือ ผมบอกได้เลยว่าในตำราที่สามารถหาได้ในอินเตอร์เน็ตนั้นมันล้าสมัย เอาหละเรามาเจาะลึกในสายที่ผมถนัดที่สุดกันดีกว่าว่ามันคืออะไร คุณเคยได้ยินคำว่า **“Carding”** หรือไม่?

### ความหมาย
* **Carding:** การฉ้อโกงทางธุรกรรมบัตรเครดิต/เดบิต คือคำจำกัดความโดยรวม
* **Carder:** เหล่าผู้ใช้บัตรเครดิตของผู้อื่นโดยที่ไม่ได้รับอนุญาต ที่ได้ซื้อมาจาก Dark-Net ต่างๆ สรุปก็คือ Carding คือชื่อวงการ ส่วน Carder คือชื่อใช้เรียกผู้ใช้งานบัตรที่ถูกขโมยมา

**บัตรเครดิตพวกนี้ถูกขโมยมายังไง?**
ต้องบอกก่อนเลยว่าในโลกนี้ไม่มีคำว่าปลอดภัย 100% แม้แต่ธนาคารเอง ข้อมูลพวกนี้หลุดออกมาจากปัจจัยหลายเหตุ มีหลักๆ อยู่ 2 ประเภท
1.  **ปัจจัยภายใน:** เช่นการ Phishing, Social engineering, SQLInjection
2.  **ปัจจัยภายนอก:** คือ Skimming เป็นต้น

### เส้นทางสู่โลกของ Carding
การเดินทางที่เริ่มต้นจากความอยากรู้ และค่อยๆ เข้าใจว่าโลกนี้ซับซ้อนกว่าที่คิดและความโลภมากในอำนาจของเงิน
ครั้งแรกที่ผมได้ยินคำว่า "Carding" ผมคิดว่ามันเป็นแค่เรื่องง่ายๆ ของการใช้ข้อมูลบัตรเครดิตที่ได้มา แล้วก็ไปซื้อของ แต่ความเป็นจริงนั้น มันซับซ้อนกว่านั้นมาก Carding ไม่ใช่แค่เรื่องของเทคนิค แต่เป็นการผสมผสานระหว่าง:
* **ความรู้ทางเทคนิค** (Technical Skills)
* **ความเข้าใจระบบการเงิน** (Financial Systems)
* **จิตวิทยา** (Psychology)
* **การจัดการความเสี่ยง** (Risk Management)
* **การปกปิดตัวตน** (Anonymity & OPSEC)

## 📚 ความรู้พื้นฐานที่จำเป็น
### 1. Networking Basics - พื้นฐานเครือข่าย 🌐
สิ่งแรกที่ต้องเข้าใจคือการทำงานของอินเทอร์เน็ต:
* **IP Address** - ที่อยู่ดิจิทัลของคุณที่เปิดเผยตัวตนได้
* **DNS** - ระบบที่แปลงชื่อเว็บไซต์เป็น IP
* **HTTP/HTTPS** - โปรโตคอลการสื่อสาร และความสำคัญของ SSL/TLS
* **Proxy, Socks5 & VPN** - เครื่องมือปกปิดตัวตนขั้นพื้นฐาน

### 2. Operating Systems - ระบบปฏิบัติการ 💻
ความเข้าใจพื้นฐานเกี่ยวกับ:
* **Windows** - OS ที่ใช้กันมากที่สุด แต่มีปัญหาเรื่อง fingerprinting
* **Linux** - ความยืดหยุ่นในการปรับแต่งและความปลอดภัยที่สูงกว่า
* **Virtual Machines** - การสร้างสภาพแวดล้อมที่แยกออกจากเครื่องจริง
* **Live OS** - การใช้งานโดยไม่ทิ้งร่องรอย

### 3. Programming Fundamentals - พื้นฐานการเขียนโปรแกรม 👩‍💻
ไม่จำเป็นต้องเป็น Programmer มืออาชีพ แต่ต้องเข้าใจ:
* **Python** - สำหรับเขียน script อัตโนมัติ
* **JavaScript** - เข้าใจว่าเว็บไซต์ทำงานอย่างไร
* **Regular Expressions** - การค้นหาและกรองข้อมูล
* **API Basics** - การสื่อสารระหว่างระบบ

### 4. Security Concepts - แนวคิดด้านความปลอดภัย 🔐
แนวคิดพื้นฐานที่ต้องเข้าใจ:
* **OPSEC (Operations Security)** - การไม่ทิ้งร่องรอย
* **Encryption** - การเข้ารหัสข้อมูล
* **Tor Network** - การสื่อสารแบบไม่เปิดเผยตัวตน
* **Cryptocurrency** - Bitcoin และความเป็นส่วนตัว

## 🐣 ประสบการณ์แรกเริ่ม

### การค้นพบโลกใหม่
ผมเข้าสู่โลกนี้ผ่าน Underground Forums ที่เต็มไปด้วยข้อมูลทั้งจริงและปลอม ตอนแรกมันเหมือนเข้าไปในโลกที่ใช้ภาษาที่คุณไม่เข้าใจ:
* CC = Credit Card
* CVV = Card Verification Value
* BIN = Bank Identification Number
* VBV = Verified by Visa
* Full = ข้อมูลครบชุดของบุคคล
* Chargeback = การเรียกเงินคืนจากธนาคาร

ทุกอย่างมีศัพท์เฉพาะ มี slang ของตัวเอง และมีวัฒนธรรมแห่งความไม่ไว้ใจ

### การทดสอบครั้งแรก - ความล้มเหลว
ผมจำได้ว่าครั้งแรกที่ลองใช้ข้อมูลบัตร มันล้มเหลวไม่ใช่แค่หนึ่งครั้งแต่เป็นสิบครั้งยี่สิบครั้ง สาเหตุที่ล้มเหลวบางทีอาจจะไม่ได้เกี่ยวกับเทคนิคมันมีเรื่องดวงและโชคเข้ามาเกี่ยว
1.  ไม่เข้าใจระบบ IP Score
2.  ใช้ Fingerprint เดิมๆ
3.  ไม่เข้าใจระบบ Anti-fraud
4.  ไม่เข้าใจพื้นฐาน ระบบบัตรและธนาคาร
5.  ไม่เข้าใจ BIN List
6.  มัวแต่หาซื้อคู่มือวิธีการมากกว่าลงมือปฏิบัติจริง

แต่การล้มเหลวเหล่านี้กลับเป็น **บทเรียนที่มีค่าที่สุด** การเรียนรู้จากความผิดพลาด ผมเริ่มเข้าใจว่า Carding ไม่ใช่เรื่องของ "มีข้อมูลบัตร = ซื้อของได้" แต่เป็นเรื่องของ:
* การวิเคราะห์ BIN
* การ Match ข้อมูล
* Anti-Fraud System
* Chargeback Risk
* การสอดแนมเว็บไซต์

## 🛠️ เครื่องมือที่เรียนรู้ในระดับนี้

### 1. Anonymity Tools - เครื่องมือปกปิดตัวตน
* **VPN Services** - NordVPN, ExpressVPN, Private Internet Access
* **SOCKS5 Proxies** - Residential proxies ที่มี geolocation ตรงกับบัตร
* **Tor Browser, Telegram** - การเข้าถึง Dark-net markets
* **Anti-detect Browsers** – Multi login, GoLogin
> ผมเริ่มจาก VPN ฟรี แล้วเข้าใจว่าต้องลงทุนกับ Residential proxy ที่ดี

### 2. Information Gathering - การรวบรวมข้อมูล
* **BIN Lookup Tools** - เช็ค BIN ว่าเป็นธนาคารไหน ประเทศไหน
* **IP Geolocation Checkers** - เช็คว่า IP ของเราอยู่ที่ไหน
* **ZIP Code Distance Calculator** - วัดระยะห่างระหว่าง IP กับ billing address
* **Email Verification Tools** - เช็คว่า email ใช้งานได้จริงหรือไม่

### 3. Testing & Validation - การทดสอบข้อมูล
* **Card Checkers** - ตรวจสอบว่าบัตรยังใช้งานได้หรือไม่
* **ENROLL Checking** - เช็คว่าบัตรมี VBV/MCSC หรือไม่
* **Balance Checkers** - ประมาณการยอดคงเหลือ (ต้องมีประสบการณ์ในระดับหนึ่ง)

### 4. Communication - การสื่อสาร
* **Encrypted Messaging** - Telegram, Jabber/XMPP
* **PGP Encryption** - การเข้ารหัสข้อความ
* **Temporary Email** - Email แบบใช้ทิ้ง
* **Virtual Phone Numbers** - เบอร์โทรศัพท์เสมือน

## 💡 สิ่งที่ได้เรียนรู้

### 1. โลกนี้ไม่ง่ายใช่อย่างที่คิด
ผมคิดว่ามันจะง่าย แต่ความจริงคือ:
* ใช้เวลาหลายเดือนและอาจจะเป็นปีๆ กว่าจะเข้าใจพื้นฐาน (ถ้ามีพื้นฐานอยู่แล้วอาจจะใช้เวลาไม่ถึงเดือน)
* ล้มเหลวมากกว่าสำเร็จ (ในช่วงเริ่มต้น)
* เสียเงินลงทุนไปเยอะก่อนจะได้อะไรกลับมา (แต่ว่าถ้าสำเร็จคุณจะจับทางได้ เพิ่มโอกาสสำเร็จไปอีก บวกผลลัพธ์ที่ได้มา 100 เท่าตัว)

### 2. ชุมชนเต็มไปด้วยมิจฉาชีพ
Underground forums หรือ Telegram มี:
* **Scammers** - ขายของปลอม ส่วนมากคนที่โดนหลอกจะเป็นพวกไม่ศึกษาข้อมูลอะไรก่อนตัดสินใจ ปัจจุบันการซื้อขายระหว่างกันนั้นง่ายและปลอดภัยมากขึ้น ใช้ Escrow และ คริปโต
* **Rippers** - คนที่หนีเอาเงิน ส่วนมากจะได้มาจาก มือใหม่ที่โภคมากเกินตัว
* **Fake Vendors** - ผู้ขายข้อมูลปลอม
* **Undercover Agents** - เจ้าหน้าที่ที่แฝงตัว จะแฝงตัวอยู่ในกลุ่มใหญ่และมีชื่อเสียงที่ดัง
> ทุกๆ อย่างมีต้นทุนทั้งหมด ไม่มีของฟรียกเว้นคุณจะใช้ PGP เทรดทรัพยากรร่วมกัน แต่คุณต้องมี สกิวในระดับนึง
> **การเรียนรู้ที่สำคัญ:** อย่าเชื่อใครง่ายๆ ต้องมี Escrow ที่เชื่อถือได้

### 3. OPSEC คือทุกอย่าง
ความผิดพลาดเล็กน้อยสามารถนำไปสู่:
* การถูกติดตาม
* การเปิดเผยตัวตน
* ปัญหาทางกฎหมาย
> ผมเห็นหลายคนที่มีทักษะดี แต่ล้มเพราะ OPSEC ที่แย่ สุดท้ายก็ไม่ได้อะไรกลับมา

### 4. เทคนิคอย่างเดียวไม่พอ
สิ่งที่ทำให้สำเร็จคือ:
* **ความอดทน** - การเรียนรู้จากความล้มเหลว
* **การวิเคราะห์** - เข้าใจว่าทำไมถึงล้มเหลว
* **การปรับตัว** - เทคนิคที่ใช้ได้วันนี้อาจไม่ได้ผลพรุ่งนี้
* **ความรอบคอบ** - ทุกรายละเอียดมีความสำคัญ
* **เงินทุน** - ทุกอย่างต้องใช้เงินทั้งหมดคุณจะต้องเสียเงินอีกเยอะและจะท้อไปในที่สุด
